- [ ] **Step 3: Implement `ui_theme.py`**

`blend` tách `#RRGGBB` thành ba số nguyên 0–255, nội suy `round(a + (b - a) * t)`, ghép lại; kiểm định dạng bằng `len(value) == 7 and value[0] == "#"` rồi `int(value[i:i+2], 16)` trong `try/except`, ném `ValueError` khi sai.
`contrast_ratio` chuẩn hoá kênh theo công thức WCAG (chia 255, gamma `((c + 0.055) / 1.055) ** 2.4` khi `c > 0.03928`, ngược lại `c / 12.92`), độ sáng `0.2126 R + 0.7152 G + 0.0722 B`, trả `(max + 0.05) / (min + 0.05)`.
`tween` chạy đệ quy:

```python
def tween(schedule, duration_ms, frame_ms=16, on_frame=None, on_done=None):
    total, step = max(1, int(duration_ms)), max(1, int(frame_ms))

    def frame(index):
        t = min(1.0, index * step / total)
        if on_frame:
            on_frame(t)
        if t >= 1.0:
            if on_done:
                on_done()
        else:
            schedule(step, lambda: frame(index + 1))

    frame(0)
```

`enable_dark_title_bar` lặp `for attribute in (20, 19)`, gọi `setter(attribute, 1)` trong `try/except Exception`, trả `True` ngay lần đầu không lỗi; hết vòng lặp trả `False`.
